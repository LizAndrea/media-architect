# CONTEXTO DEL CLIENTE

Este archivo define el contexto específico de este cliente.

## 1. NOMBRE DEL CLIENTE
Cody

## 2. BRAND GUIDELINES
- Valores de marca: Referente tech-entretenido, identidad local boliviana (Cochabamba), multifacético (programador, ciclista MTB, foodie local, aventurero).
- Tono y estilo de comunicación: Entretenido, tech-savvy, cercano, aventurero, curioso.
- Audiencia objetivo: Comunidad en TikTok y RRSS, enfocada en tecnología, programación, ciclismo de montaña, turismo local y comida.

## 3. IDENTIDAD VISUAL
- **Diseño del Personaje:** Robot humanoide (semi-realista/3D) con hoodie negro estampado "DECODER" y símbolos de código, auriculares over-ear. Postura dinámica, no rígida. Ojos expresivos que cambian de color (Azul/Cyan: normal, Verde: emoción, Rojo: error, Amarillo parpadeante: thinking). Piel metálica con textura sutil.
- **Colores principales:**
  - Fondo/Tech: `#0A0E17`, `#1A1F2E`
  - Acentos Tech: `#00D4FF`, `#7B61FF`
  - Acentos MTB/Aventura: `#00FF88`, `#FF6B35`
  - Acentos Comida/Local: `#FFB800`, `#FF4757`
- **Texto:** Blanco (`#FFFFFF`) con sombra oscura o fondo semi-transparente.
- **Estilo de fondos:** Developer room del futuro cyberpunk sutil (luces LED, circuitos, monitores, bici, casco). Para exteriores/comida, usar fondos ilustrados digitales realistas/semi-realistas de locaciones de Cochabamba.
