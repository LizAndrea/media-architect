# WORKFLOW GENERAL DE MEDIA-ARCHITECT

1. `/media-new-client` para registrar la marca.
2. `/media-in` para cargar el contexto.
3. `/media-new` para inicializar el proyecto (ej. YouTube, Short).
4. `/media-script` para generar el guion y validarlo.
5. `/media-storyboard` para planear las tomas.
6. `/media-render` para preparar las escenas y prompts IA.
7. Generar en plataformas IA externas (Google Flow, Runway, etc.) basándose en los prompts.
8. `/media-assets` para registrar resultados en el repositorio.
9. Edición final externa (Premiere, Resolve, CapCut).
10. `/media-commit` durante todo el proceso.
