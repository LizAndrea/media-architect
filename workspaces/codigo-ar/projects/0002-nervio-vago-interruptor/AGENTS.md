# CONTEXTO DEL PROYECTO DE VIDEO

Este archivo define el contexto específico de este proyecto de video.

## 1. METADATA DEL PROYECTO
- **Nombre:** El Nervio Vago: Tu Interruptor Anti-Dolor
- **Tipo de video:** Reel de Instagram / Short
- **Duración objetivo:** ~60 segundos
- **Plataformas de destino:** Instagram Reels, TikTok, YouTube Shorts

## 2. VISIÓN CREATIVA
Este video aborda la relación directa entre el estrés crónico (sistema nervioso simpático activo) y los brotes de dolor por Artritis Reumatoide. El mensaje clave es que el Nervio Vago es el "interruptor" para apagar la inflamación mediante la respiración diafragmática. El objetivo es empoderar al paciente validando primero su experiencia con el dolor y luego brindando una herramienta gratuita, inmediata y científica.

## 3. AUDIENCIA Y TONO
- **Audiencia:** Personas (principalmente mujeres) diagnosticadas con Artritis Reumatoide o enfermedades autoinmunes similares, que se sienten frustradas porque sus brotes empeoran con el estrés, y que buscan explicaciones lógicas y herramientas funcionales.
- **Tono:** Empático, validante y luego directo y educativo. Se utiliza la figura de guía empoderadora (LIA) sin caer en el victimismo ni promesas milagrosas.
