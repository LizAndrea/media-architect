# Workspace: NOVA HOME & TECH

Bienvenido al workspace **NOVA**. 
Este entorno está optimizado para la producción masiva de contenido viral y anuncios publicitarios de alta conversión, utilizando las técnicas más agresivas de neuromarketing y directrices cinematográficas (High-End Commercials).

Abarca tanto la comercialización de **productos físicos** (gadgets para el hogar y tecnología importada) como de **productos digitales** (Gemini Pro, eBooks, servicios publicitarios).

## Estructura
- `workspace.yaml`: Configuración técnica, colores de marca y estética visual.
- `AGENTS.md`: Reglas creativas, comportamiento del agente, estrategias de neuromarketing viral y arquetipos publicitarios.
- `projects/`: Donde vivirán los proyectos audiovisuales (Ads, TikToks, Tutoriales).
- `characters/`: Donde se guardan las hojas de referencia (Ej. de nuestra mascota virtual **Tuki**).
- `assets/`: Recursos gráficos y de audio.

## Flujo de Trabajo Recomendado
1. **`/media-character`** para registrar o refinar a la mascota Tuki o a portavoces específicos.
2. **`/media-new`** para crear un proyecto (ej. `0001-ad-gemini-pro` o `0002-viral-unboxing-gadget`).
3. **`/media-script`** para escribir un guion letal aplicando hooks visuales y neuromarketing.
4. **`/media-render`** para extraer los prompts precisos de cada escena para la generación con IA.
