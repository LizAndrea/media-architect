# 0002-5-cosas-gemini

## Descripción del Proyecto
Este es un proyecto de contenido de valor (educativo/viral) estructurado en formato **"Video Podcast" o "Vodcast" corto (formato vertical)**. El objetivo es desmitificar la Inteligencia Artificial mostrando 5 trucos o usos súper prácticos y novedosos de **Gemini AI** que la persona común no sabe que existen, y que son muy fáciles de usar.

## Actores Involucrados
- **Camila:** Guía tecnológica y anfitriona del podcast.

## Formato
- **Video Podcast / Vodcast:** Camila está sentada en un set de oficina moderna (estilo NOVA), frente a un micrófono de estudio (estilo Shure SM7B). Esto transmite autoridad, intimidad y un ritmo conversacional dinámico.
