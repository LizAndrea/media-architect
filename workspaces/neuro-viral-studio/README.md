# Neuro Viral Studio Workspace

Bienvenido al workspace **Neuro Viral Studio**. 
Este entorno está configurado con reglas avanzadas de neuromarketing y directrices cinematográficas ultra-realistas.

## Estructura
- `workspace.yaml`: Configuración técnica y estética de la marca.
- `AGENTS.md`: Reglas creativas, comportamiento del agente, neuromarketing y estructura de prompts de video.
- `projects/`: Donde vivirán los proyectos audiovisuales.
- `characters/`: Donde se guardarán las fichas de los avatares / personajes generados para mantener continuidad.
- `assets/`: Recursos gráficos y de audio de la productora.

## Flujo de Trabajo Recomendado
1. **`/media-character`** (Puedes usar o crear un prompt para hoja de referencia).
2. **`/media-new`** para crear un proyecto viral (ej. `0001-tutorial-viral-react`).
3. **`/media-script`** para escribir el guion aplicando las reglas del `AGENTS.md`.
4. **`/media-render`** para obtener los prompts precisos de cada escena estructurados para Flow AI o similares.
