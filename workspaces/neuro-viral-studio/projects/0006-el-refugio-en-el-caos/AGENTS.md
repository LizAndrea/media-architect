# CONTEXTO DEL PROYECTO DE VIDEO

Este archivo define el contexto específico de este proyecto de video.

## 1. METADATA DEL PROYECTO
- **Nombre:** El refugio en el caos
- **Tipo de video:** Spec Ad Íntimo (Short/TikTok)
- **Duración objetivo:** ~10-15 segundos
- **Plataformas de destino:** TikTok, Instagram Reels, YouTube Shorts

## 2. VISIÓN CREATIVA
Un gancho puramente visual. Una luz de atardecer espectacular (golden hour), que actúa como un "parada obligatoria" amigable en el algoritmo, invitando a detener el scroll infinito para simplemente existir. El objetivo es dar paz y ser un refugio.

## 3. AUDIENCIA Y TONO
- **Audiencia:** Gen Z, Millennials lidiando con sobrecarga de información y agotamiento digital.
- **Tono:** Empático, pacífico, cálido, seguro y de validación emocional.
